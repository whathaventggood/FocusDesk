# FocusDesk 3.2.0（构建 9）开发与深度自测报告

日期：2026-11-09。平台：macOS 13+ / Apple Silicon。范围：当前工作区的 macOS 应用。本报告记录本地验收结果；GitHub 自动检查以对应提交的 Actions 结果为准。未读取或修改日常学习数据。

## 已完成的功能

- **日期固定明细**：保留单柱块悬停，点击日期或柱子后固定展示当天项目与时长；支持空日期、方向键和辅助日期动作，查看记录时携带日期及项目上下文。
- **项目查找与聚焦**：搜索只缩小候选列表，明确点击“只看此项目”后更新图表；提供返回全部。多项目图例默认显示六项，可展开全部，选中项目优先展示。
- **最近项目和参数记忆**：最近三个项目可明确点击开始；保存各项目的计时方式和倒计时参数，并记住统计范围、排序、筛选和页面。恢复窗口或偏好不会自动开始计时。
- **归档和恢复**：归档项目退出开始候选和最近项目，历史累计、记录、编号和颜色保留；统计中仍可查找，恢复后沿用原项目。当前计时和待完成提醒所属项目需先完成再归档。
- **记录与备注**：记录按开始日期分组，可按项目、日期及内容查找；跨日筛选匹配当天有效片段。可选备注与时长可以一起保存；仅补备注保留原始精确时长。计时结束后提供轻量补充内容入口，不强制弹出表单。
- **原子切换计时**：以同一时间点结束 A 并开始 B；目标无效则保留完整原状态。持久化切换来源，使保存中睡眠、延迟到达的暂停恢复记录和重新读入均能排除睡眠时间。
- **撤销与重做**：支持项目名称、归档、时长和备注修改；按具体字段恢复，保留后来新增的记录，较新的外部修改会阻止冲突撤销。菜单描述具体操作；编辑文字时优先撤销文字。
- **页面分区与观感**：计时、学习统计、学习记录分区，统计和记录页保留当前计时条；计划完成率入口明确命名为“计划回顾”。新建项目表单可展开，多主题与长名称布局保留。

## 配套改进

- 首次和历史变化后的统计使用后台创建、单次移交的缓存，避免共享可变缓存；主界面继续增量计算运行片段。未变更轮询和只改项目名称复用统计。
- 空闲时内部时钟的计时文件轮询降低到每五秒；显式刷新、激活、睡眠、唤醒和运行中的倒计时保持及时处理。
- 计时数据格式升级为版本 2。旧文件第一次替换前创建逐字节备份；中断重试保留原备份，后来重新出现的不同旧文件另存备份。旧版程序不支持写入新格式，避免丢失归档或备注字段。
- 保存使用紧凑、确定键序的 JSON，减少文件体积；安装包和现有版本信息显示 3.2.0 / 构建 9。
- 构建在独立临时目录签名，生成版本化 ZIP，并保存源码与安装包哈希，避免交付错包。

## 性能与测量范围

| 组件测量 | 10,000 条记录 | 100,000 条记录 |
| --- | --- | --- |
| 首次统计快照（组件方法） | 12.1871 ms | 91.6926 ms |
| 运行片段增量统计 | 0.0054 ms | 0.0054 ms |
| 只改项目名称的统计更新 | 0.7715 ms | 0.8448 ms |
| 首次读入文件 | 81.4799 ms | 830.9098 ms |
| 未变更文件同步 | 0.0811 ms | 0.0766 ms |
| 5,000 次索引命中 | 11.7018 ms | 13.0673 ms |

上表为组件耗时，**不等同于整页渲染、真实鼠标延迟或完整保存时间**。首次统计准备的移交与复用另有 Foundation 检查，已验证主界面接收缓存后不会因修订号不同再次建立同一索引。

相同单片段、100 项目、临时目录的改名保存探针，每种规模采样 5 次：

| 记录数 | 原文件 → 紧凑文件 | 原保存中位数 → 本次中位数 |
| --- | --- | --- |
| 1,000 | 0.33 MB → 0.22 MB | 15.3 ms → 16.3 ms |
| 10,000 | 3.24 MB → 2.09 MB | 124.9 ms → 132.4 ms |
| 100,000 | 32.31 MB → 20.81 MB | 1278.1 ms → 1329.0 ms |

文件体积减少约 35%–36%；本轮保存时间未显示稳定提速，十万条记录仍有约 1.3 秒的后台保存成本，期间提供保存反馈。五次样本不是 P95，不据此承诺所有设备的响应时间。原始结果为 `build/ux-validation/performance.json`、`build/ux-validation/performance-stress.json`、`build/ux-validation/save-probe-current.json`。
