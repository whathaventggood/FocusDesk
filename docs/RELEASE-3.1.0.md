## FocusDesk 3.1.0 · 屏幕到时特效 / Screen effects

倒计时提醒可从方块扩散到半屏、大半屏或整个屏幕。无声、鼠标穿透、不抢焦点，所有个人数据仍仅保存在各设备本机。

- 覆盖范围 10%–100%；四种预设：轻柔 15%、标准 50%、夸张 85%、全屏沉浸 100%。
- 单独调整浓度、总时长 1–12 秒、扩散速度、1–3 波、粒子密度、边缘余光和背景压暗。
- 方块起势 → 粗光带扩散与主题粒子 → 边缘余光；设置/菜单栏/托盘可立即停止。
- 默认方块所在屏幕，可开启所有显示器。遵循系统减少动态效果，无需屏幕录制权限。
- 旧强度偏好自动迁移；计时、计划和历史保持兼容，支持中英文切换。

### English

Countdown effects now spread across 10–100% of the screen. Presets: Gentle 15%, Standard 50%, Dramatic 85%, Full-screen immersive 100%. Independently adjust opacity, total duration (1–12 seconds), expansion speed, waves, particles, edge glow, and dimming. Preview on the actual desktop and dismiss from Settings or the menu/tray. Optional all-monitor playback. Silent, click-through, focus-preserving, and reduced-motion aware. No personal-data synchronization.

### Downloads / 安装

Four packages: macOS 13+ Apple Silicon and Windows 10/11 x64, each with Simplified Chinese or English default. Both editions can switch languages in Settings. Windows: extract the whole folder, keep every file, and run FocusDesk.exe; .NET included. macOS: quit the old app and replace it in Applications. Back up local data before upgrading.

Community signatures remain unchanged: macOS ad-hoc signed, not notarized; Windows unsigned. SHA-256 checksums attached. Native rendering varies slightly by OS. Protected/exclusive full-screen surfaces may limit overlays; physical mixed-DPI/multi-monitor setups need broader verification.
